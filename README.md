# study with yuri — multi-page studio 🌸

a 7-page pink-dominant, minimal student studio formatted strictly in lowercase, using semantic html5, shared css with mobile media queries, and vanilla javascript with localstorage persistence.

## pages included
1. `index.html` — home dashboard
2. `focus.html` — focus room
3. `planner.html` — my planner (month-switching calendar + full task manager with add/edit/delete/complete, counts, %, priority, and optional due date)
4. `study.html` — study corner (quick notes, flashcards with delete button, subject organization)
5. `future.html` — letter to my future self (time capsule letters with unlock dates)
6. `progress.html` — my progress
7. `settings.html` — settings
